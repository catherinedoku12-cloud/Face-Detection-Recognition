# Face Detection and Recognition Project

## Project Overview
This repository contains the codebase, dataset preparation workflows, and model evaluations for an image-based face detection and recognition system. The project covers data collection, image annotation, regression modeling, and deep learning-based object detection.

## Project Structure & Workflow
1. **Data Collection & Preparation:** Gathering initial batches of custom facial image datasets organized via Google Drive.
2. **Data Annotation:** Labeling facial bounding boxes and class attributes for model training.
3. **Model Development:** Training custom models utilizing Ultralytics (YOLO) alongside local evaluation workflows.
4. **Model Evaluation:** Performance assessment using Confusion Matrices, ROC curves, and AUC metrics.

## Tools & Environment
- **Python** (Development environment)
- **Ultralytics** (YOLO object detection framework)
- **Ollama** (Local LLM environment running `llama3.2:1b`)
- **Google Drive & Colab** (Storage and cloud-accelerated training)
- **Git & GitHub** (Version control and project tracking)
